# Results

This directory contains selected figures and LaTeX tables associated with the manuscript.

| Path | Description |
|---|---|
| `figures/` | PDF and PNG versions of selected study figures. |
| `tables/` | LaTeX table sources and `SOURCE_MAP.json`, which maps table values to result files. |

Figures and tables are generated from the scripts under `experiments/` and `code/exp_arcs/`. The source map supports value tracing; it does not constitute an independent rerun of the complete study.
