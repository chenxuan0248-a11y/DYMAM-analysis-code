# Analysis Code

This directory contains the ARCS analysis and evaluation code associated with the paper. It does not include the full DyMAM runtime system or the host-level inputs and per-run result JSON used in the study.

| Path | Description |
|---|---|
| `exp_arcs/` | Main fault-injection analysis scripts. |
| `exp_arcs/revision_v2/` | Supplemental analysis scripts from the revision cycle. |
| `evaluation/` | Metric, calibration, ranking, and statistical-test helpers. |
| `pyproject.toml` | Python dependency declarations. |

The included figures and tables are aggregate outputs. The code is provided for inspection; the withheld inputs prevent complete reproduction of all reported measurements.
